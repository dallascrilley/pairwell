# Contributing

Thanks for taking a look. Issues and pull requests are welcome.

## Setup

Requires Node.js 22+, Docker, and network access to `data.texas.gov` for the full demo.

```bash
./scripts/demo.sh
```

See the README for the expected match summary and the 21,875-record sampling note.
